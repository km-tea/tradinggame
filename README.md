# 무역 항구 게임

Netlify + Neon Postgres 기반 학급용 무역 게임입니다.

## 여러 학급에서 동시에 이용하기

- 학급 코드별로 게임 데이터 공간이 분리됩니다. 같은 Netlify 주소와 Neon 데이터베이스를 사용해도 서로 다른 학급 코드로 입장하면 게임 시간, 모둠 입장 코드, 자원, 제작 기록, 무역 제안, 순위가 섞이지 않습니다.
- 교사와 학생은 반드시 같은 학급 코드를 입력해야 합니다. `기본학급` 또는 `default`는 기존 `public` 게임 공간으로 연결됩니다.
- 서버는 학급 코드를 해시한 PostgreSQL 스키마를 사용하며, 필요한 테이블은 자동으로 준비됩니다. 별도의 SQL을 실행할 필요가 없습니다.

## 모둠 수 및 시작 재화

- 교사는 게임 시작 전에 5개 모둠(축소형) 또는 10개 모둠(기본형)을 선택할 수 있습니다.
- 각 모둠은 특산 재화 8개, 다른 핵심 재화 2개와 1개를 무작위로 받고 달러 $150을 받습니다.
- 5개 모둠에서는 핵심 재화 5종을 각각 한 모둠씩, 10개 모둠에서는 각 재화를 두 모둠씩 특산 재화로 배정합니다.

## 나라 이름 정하기

- 학생은 자급자족 시간에 만들기 탭에서 모둠을 대표할 나라 이름을 정해 저장할 수 있습니다.
- 같은 학급 안에서는 중복된 나라 이름을 사용할 수 없으며, 이름은 16자 이내로 입력합니다.
- 나라 이름은 무역·순위·교사 현황에 표시됩니다. 새 게임 시작 또는 전체 초기화 시 이름은 `1모둠`, `2모둠`처럼 기본값으로 돌아갑니다.

## 배포

주요 파일은 `public/index.html`과 `netlify/functions/api.mjs`입니다. GitHub에 변경 파일을 올리면 Netlify가 자동 배포하도록 설정할 수 있습니다. Netlify 환경 변수 `DATABASE_URL`에는 기존 Neon 연결 문자열을 사용합니다.

## 중요 안내

학급 코드는 데이터 공간을 구분하는 용도이지, 강력한 비밀번호를 대신하지 않습니다. 학생에게는 학급 코드와 해당 모둠의 입장 코드를 함께 안내하세요. 교사 비밀번호는 학생에게 공개하지 마세요.

## 가공품 조합식 무작위 적용

- 가공품 조합식 선택지는 기존 16종에서 21종으로 늘렸습니다(기본 1종, 심화 2종, 최종 2종 추가).
- 새 게임을 시작할 때 기본 가공품 3종(후보 9종), 심화 가공품 3종(후보 7종), 최종 완성품 2종(후보 5종)이 무작위로 선택됩니다.
- 심화·최종 조합은 해당 게임에서 선택된 앞 단계 가공품을 재료로 사용하도록 조합을 맞춥니다. 따라서 선택되지 않은 가공품을 요구해 제작이 막히는 상황을 방지합니다.
- 선택된 가공품과 조합식은 해당 게임 동안 유지되며, 다음 게임 시작 때 새로 무작위 선택됩니다.
- 서버는 선택되지 않은 가공품 제작 요청을 거부합니다. `tg_game.active_products` 열은 자동으로 추가되므로 별도 SQL 실행은 필요하지 않습니다.
