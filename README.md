# 무역 항구 게임 (Netlify + Neon)

10개 모둠이 특산품과 보조 자원을 가지고 시작해, 서로 무역하며 물품을 만드는 수업 활동 앱입니다.

## 배포 순서
1. **Neon**: 새 프로젝트를 만들고 *Connection string*(`postgresql://...`)을 복사합니다. 표(테이블)는 처음 접속할 때 자동으로 만들어지며, 이름이 모두 `tg_`로 시작해서 다른 앱과 섞이지 않습니다.
2. **GitHub**에 이 폴더 전체를 올리고, **Netlify**에서 *Import from Git*으로 연결합니다. (빌드 명령은 비워 두면 됩니다.)
3. Netlify → Site configuration → Environment variables 에 아래 두 개를 추가한 뒤 다시 배포합니다.
   - `DATABASE_URL` : Neon 연결 문자열
   - 교사 입장 코드는 `1234`로 고정되어 있습니다. `TEACHER_PIN` 환경변수는 필요하지 않습니다.

## 수업 진행 (20분)
| 시간 | 내용 |
|---|---|
| 2분 | 규칙 설명 (모둠마다 재료 1가지, 물품 조합식, 미션 카드) |
| 2분 | 자급자족 시간 – 무역 금지, 혼자서는 아무것도 못 만든다는 것을 체험 |
| 12분 | 무역 시간 – 학생이 직접 쓴 제안문으로 거래, 물품 제작 |
| 4분 | 결과 화면의 "무역 전후 비교"를 보며 토론 |

모둠은 10개로 고정되어 있습니다. 별도 `모둠별 자원 지급` 탭에서 특정 모둠에 목재·철광석·면화·식량·석유를 추가 지급할 수 있습니다. 시작 전 지급한 자원은 게임 시작 후에도 유지됩니다. 게임 시작 시 각 모둠은 특산품 10개와, 특산품을 제외한 무작위 보조 자원 2종(각각 3개와 2개)을 받습니다. 교사 입장 코드는 `1234`입니다.

## 사용 방법
- 교사: 접속 → `교사` 탭 → 코드 `1234` 입력 → 필요하면 `모둠별 자원 지급` 탭에서 자원 추가 → 입장 코드표를 모둠에 알려 주고 `게임 시작` → `무역 열기` → `게임 끝내기`
- 모둠: 접속 → 모둠 번호 + 4자리 입장 코드 입력
- `초기화`를 누르면 기록이 지워지고 입장 코드가 새로 만들어집니다.

## 규칙 요약
- 기본 재화는 목재·철광석·면화·식량·석유의 5종입니다. 특산품은 2개 모둠씩 공유합니다: 1~2모둠 목재 / 3~4모둠 철광석 / 5~6모둠 면화 / 7~8모둠 식량 / 9~10모둠 석유. 금은 게임에서 사용하지 않습니다.
- 기본 가공품은 재료 2종으로 제작하며 각 30점, 심화 가공품은 기본 가공품 1개와 기본 재화 1종으로 제작하며 각 100점, 최종 완성품은 심화 가공품 1개와 기본 재화 2종으로 제작하며 각 200점입니다.
- 첫 미션은 기본 가공품 1개 만들기(10점)이며, 달성할 때마다 다음 미션이 자동 배정됩니다. 미션 보상은 10점씩 증가하고, 새 미션의 진행도는 배정된 시점부터 계산됩니다.
- 제안문은 10글자 이상, 수락 답장은 5글자 이상 직접 써야 합니다.
- 타이머는 안내용입니다. 시간이 0이 되어도 교사가 끝낼 때까지 계속 진행됩니다.

## 물품 조합식
| 단계 | 물품 | 조합식 | 점수 |
|---|---|---|---:|
| 기본 가공품 | 건설 자재 묶음 | 목재 1 + 철광석 1 | 30점 |
| 기본 가공품 | 생활용품 세트 | 면화 1 + 식량 1 | 30점 |
| 기본 가공품 | 종이·포장재 묶음 | 목재 1 + 면화 1 | 30점 |
| 기본 가공품 | 농업 도구 세트 | 철광석 1 + 식량 1 | 30점 |
| 심화 가공품 | 스마트 기기 | 건설 자재 묶음 1 + 석유 1 | 100점 |
| 심화 가공품 | 고급 의류 | 생활용품 세트 1 + 면화 1 | 100점 |
| 심화 가공품 | 응급 구호 키트 | 농업 도구 세트 1 + 석유 1 | 100점 |
| 최종 완성품 | 첨단 도시 모형 | 스마트 기기 1 + 철광석 1 + 목재 1 | 200점 |
| 최종 완성품 | 지속 가능한 미래 세트 | 고급 의류 1 + 식량 1 + 석유 1 | 200점 |

## 태블릿 사용
- 화면 폭에 맞춰 조합식 카드가 2열 또는 1열로 자동 배치됩니다.
- 하단 학생 메뉴와 상단 교사 도구는 터치 조작에 적합하도록 버튼 높이와 간격을 넓혔습니다.
- 교사 현황 표는 좁은 화면에서 가로로 스크롤할 수 있습니다.


## 성능 개선 사항

- 교사 입장 코드 `1234` 검증은 데이터베이스 연결 없이 처리해 로그인 확인 응답을 빠르게 했습니다.
- 최초 DB 초기화 시 모둠 및 재고 행을 개별 반복 쿼리 대신 묶음 쿼리로 생성해 초기 로딩 지연을 줄였습니다. 기존 모둠 입장 코드와 보유 재고는 보존됩니다.
