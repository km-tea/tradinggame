# 무역 항구 게임 (Netlify + Neon)

초등학교 수업용 모둠 무역 게임입니다. GitHub 저장소에 이 폴더의 **내용물**을 저장소 최상위에 올리면, 연결된 Netlify가 자동으로 배포할 수 있습니다.

## 배포

- `public/index.html`: 학생·교사 화면
- `netlify/functions/api.mjs`: 서버 기능
- `netlify.toml`: Netlify 설정
- `package.json`: 서버 의존성
- Netlify 환경 변수 `DATABASE_URL`에 기존 Neon 연결 문자열이 설정되어 있어야 합니다.
- 데이터베이스 테이블과 필요한 스키마는 앱에서 자동으로 준비합니다. 기존 Neon 데이터를 초기화하지 마세요.

## 게임 기능

- 교사는 5개 또는 10개 모둠으로 게임을 구성할 수 있습니다.
- 학생은 자급자족 단계에 모둠의 나라 이름을 정할 수 있습니다.
- 게임 시작 시 모둠별 특산 재화, 보조 재화와 달러가 지급됩니다.
- 가공품 조합식은 게임 시작 시 무작위로 선정되며, 상위 단계 조합은 해당 게임에 선정된 하위 단계 제품을 기준으로 구성됩니다.
- 교사는 `모둠별 자원 지급` 기능에서 특정 모둠에 기본 재화 또는 달러를 추가 지급할 수 있습니다. 게임 진행 중에도 지급할 수 있습니다.
- 무역 단계가 시작된 뒤 1분마다 모둠별 특산 재화 3개와 다른 기본 재화 1개가 지급됩니다. 자급자족 단계에서는 이 시간 지급이 시작되지 않습니다. 무역 중 일시 정지했다가 재개하면 다음 지급까지 1분을 새로 계산합니다.
- 교사 화면과 학생 화면의 반복 갱신 및 네트워크 오류 처리를 개선해 불필요한 갱신과 중복 요청을 줄였습니다.
- 기존 학급 분리, 나라 이름, 제작, 무역 제안, 국내 생산, 순위 등의 기능을 유지합니다.

## GitHub에 올리는 방법

ZIP 파일 자체를 저장소에 올리는 것이 아니라, 압축을 푼 뒤 `public`, `netlify`, `package.json`, `netlify.toml`, `README.md`가 저장소 최상위에 오도록 파일을 반영합니다. Netlify가 GitHub 저장소와 연결되어 있으면 커밋 이후 자동 배포가 시작됩니다.
