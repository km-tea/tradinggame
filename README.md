# 무역 항구 게임 (Netlify + Neon)

10개 모둠이 특산품과 보조 자원을 가지고 시작해, 서로 무역하며 물품을 만드는 수업 활동 앱입니다.

## 배포 순서
1. **Neon**: 새 프로젝트를 만들고 *Connection string*(`postgresql://...`)을 복사합니다. 표(테이블)는 처음 접속할 때 자동으로 만들어지며, 이름이 모두 `tg_`로 시작해서 다른 앱과 섞이지 않습니다.
2. **GitHub**에 이 폴더 전체를 올리고, **Netlify**에서 *Import from Git*으로 연결합니다. (빌드 명령은 비워 두면 됩니다.)
3. Netlify → Site configuration → Environment variables 에 아래 두 개를 추가한 뒤 다시 배포합니다.
   - `DATABASE_URL` : Neon 연결 문자열
   - 교사 입장 코드는 `1234`로 고정되어 있습니다. `TEACHER_PIN` 환경변수는 필요하지 않습니다.

## 수업 진행 (20분)
| 시간 | 내용 |
|---|---|
| 2분 | 규칙 설명 (모둠마다 재료 1가지, 물품 조합식, 달러 거래) |
| 2분 | 자급자족 시간 – 무역 금지, 혼자서는 아무것도 못 만든다는 것을 체험 |
| 12분 | 무역 시간 – 물품 또는 달러를 제안해 거래하고 물품 제작 |
| 4분 | 결과 화면의 "무역 전후 비교"를 보며 토론 |

모둠은 10개로 고정되어 있습니다. 별도 `모둠별 자원 지급` 탭에서 특정 모둠에 목재·철광석·면화·식량·석유·달러를 추가 지급할 수 있습니다. 시작 전 지급한 자원은 게임 시작 후에도 유지됩니다. 게임 시작 시 각 모둠은 특산품 12개와, 특산품을 제외한 무작위 보조 자원 2종(각각 3개와 2개), 시작 자금 $100을 받습니다. 교사 입장 코드는 `1234`입니다.

## 사용 방법
- 교사: 접속 → `교사` 탭 → 코드 `1234` 입력 → 필요하면 `모둠별 자원 지급` 탭에서 자원 추가 → 입장 코드표를 모둠에 알려 주고 `게임 시작` → `무역 열기` → `게임 끝내기`
- 모둠: 접속 → 모둠 번호 + 4자리 입장 코드 입력
- `초기화`를 누르면 기록이 지워지고 입장 코드가 새로 만들어집니다.

## 규칙 요약
- 기본 재화는 목재·철광석·면화·식량·석유의 5종이며, 거래와 국내 생산에 사용할 수 있는 달러도 모둠마다 $100씩 받습니다. 특산품은 2개 모둠씩 공유합니다: 1~2모둠 목재 / 3~4모둠 철광석 / 5~6모둠 면화 / 7~8모둠 식량 / 9~10모둠 석유. 금은 게임에서 사용하지 않습니다.
- 기본 가공품은 재료 2종으로 제작하며 각 $30, 심화 가공품은 기본 가공품 1개와 기본 재화 1종으로 제작하며 각 $100, 최종 완성품은 심화 가공품 2개와 기본 재화 1종으로 제작하며 각 $200입니다.
- 미션은 사용하지 않습니다. 난이도 1·2·3 물품을 제작해 금액($)을 쌓고, 달러나 재화를 거래해 필요한 재료를 확보합니다.
- 무역 제안문과 수락·거절 답장은 선택 사항입니다. 받은 제안이 도착하면 화면에 응답 창이 나타나 수락 또는 거절을 선택해야 다음 활동을 계속할 수 있습니다.
- 타이머는 안내용입니다. 시간이 0이 되어도 교사가 끝낼 때까지 계속 진행됩니다.

## 태블릿 사용
- 화면 폭에 맞춰 조합식 카드가 2열 또는 1열로 자동 배치됩니다.
- 하단 학생 메뉴와 상단 교사 도구는 터치 조작에 적합하도록 버튼 높이와 간격을 넓혔습니다.
- 교사 현황 표는 좁은 화면에서 가로로 스크롤할 수 있습니다.


## 성능 개선 사항

- 교사 입장 코드 `1234` 검증은 데이터베이스 연결 없이 처리해 로그인 확인 응답을 빠르게 했습니다.
- 최초 DB 초기화 시 모둠 및 재고 행을 개별 반복 쿼리 대신 묶음 쿼리로 생성해 초기 로딩 지연을 줄였습니다. 기존 모둠 입장 코드와 보유 재고는 보존됩니다.


## 학생 무역 탭 추가 기능
- **모둠 창고 둘러보기**: 학생은 무역 탭에서 모둠 번호를 눌러 각 모둠의 기본 재화와 가공품 보유량을 확인할 수 있습니다. 입장 코드 등 인증 정보는 공개하지 않습니다.
- **재화 교환 상점**: 무역 시간이 열리고 게임이 일시 정지되지 않은 동안, 각 모둠이 선택한 재화 한 종류 2개를 내고 다른 종류의 재화 1개를 받을 수 있습니다. 달러도 교환할 수 있으며, 보유량이 부족한 교환은 서버에서 거부합니다. 모둠별 이용 횟수는 게임당 5회입니다.


## 최근 개선
- 상태 확인 때마다 실행하던 미션 진행·보상 처리 트랜잭션을 제거해 반복 데이터베이스 작업을 줄였습니다. 학생 화면은 5초 간격으로 상태를 확인하며, 제작·거래 등 행동 직후에는 즉시 갱신합니다.
- 모든 제작 금액과 순위는 점수 대신 달러($)로 표시합니다.
- 받은 무역 제안은 화면 중앙의 응답 창에서 수락 또는 거절을 선택해야 합니다.
