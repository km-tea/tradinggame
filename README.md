# 무역 항구 게임

Netlify + Neon Postgres 기반 학급용 무역 게임입니다.

## 여러 학급에서 동시에 이용하기

이 버전은 **학급 코드별로 게임 데이터 공간을 분리**합니다. 같은 Netlify 주소와 같은 Neon 데이터베이스를 사용해도 서로 다른 학급 코드로 입장하면 게임 시간, 모둠 입장 코드, 자원, 제작 기록, 무역 제안, 순위가 서로 섞이지 않습니다.

1. 교사가 게임에 입장할 때 학급 코드(예: `6-1`, `6-2`, `5-3`)를 입력합니다.
2. 해당 학급 학생들도 교사와 **똑같은 학급 코드**를 입력합니다.
3. 각 학급은 별도로 게임을 시작하고 진행합니다.
4. 교사는 학급별로 게임을 운영하려면 각 학급 코드로 다시 입장합니다. 교사 비밀번호는 기존 설정을 따릅니다.
5. 학급 코드를 다르게 입력하면 별도의 게임 공간이 만들어지므로 대소문자/띄어쓰기/하이픈을 정확히 맞춰야 합니다.

`기본학급` 또는 `default` 코드는 이전 버전의 기존 게임 데이터가 있는 `public` 공간으로 연결됩니다. 기존 세션처럼 학급 코드가 없는 요청도 기존 공간으로 연결해 이전 데이터를 보존합니다.

### 데이터 분리 방식

서버는 학급 코드를 해시한 PostgreSQL 스키마를 사용합니다. 새 학급이 처음 접속하면 해당 공간의 게임·모둠·창고·제작·무역 테이블을 자동으로 준비합니다. 별도의 SQL을 수동으로 실행할 필요가 없습니다. 기존 `public` 공간의 데이터는 삭제하거나 이동하지 않습니다.

## 배포

- `public/index.html`
- `netlify/functions/api.mjs`
- `package.json`
- `netlify.toml`

GitHub에 변경 파일을 올리면 Netlify가 자동 배포하도록 설정할 수 있습니다. Netlify 환경 변수 `DATABASE_URL`은 기존 Neon 연결 문자열을 그대로 사용합니다.

## 중요 안내

학급 코드는 데이터 공간을 구분하는 용도이지, 강력한 비밀번호를 대신하지 않습니다. 학생에게는 학급 코드와 해당 모둠의 입장 코드를 함께 안내하세요. 교사 비밀번호는 학생에게 공개하지 마세요.
