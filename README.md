# 무역 항구 게임 (Netlify + Neon)

6개 모둠이 특산품 1가지씩만 가지고 시작해, 서로 무역해야만 물품을 만들 수 있는 20분짜리 수업 활동 앱입니다.

## 배포 순서
1. **Neon**: 새 프로젝트를 만들고 *Connection string*(`postgresql://...`)을 복사합니다. 표(테이블)는 처음 접속할 때 자동으로 만들어지며, 이름이 모두 `tg_`로 시작해서 다른 앱과 섞이지 않습니다.
2. **GitHub**에 이 폴더 전체를 올리고, **Netlify**에서 *Import from Git*으로 연결합니다. (빌드 명령은 비워 두면 됩니다.)
3. Netlify → Site configuration → Environment variables 에 아래 두 개를 추가한 뒤 다시 배포합니다.
   - `DATABASE_URL` : Neon 연결 문자열
   - `TEACHER_PIN` : 교사 화면 비밀번호 (필수). 코드 어디에도 없는 값으로 정하세요. 너무 흔하거나 짧은 숫자는 Netlify 보안 검사에 걸릴 수 있어요.

## 수업 진행 (20분)
| 시간 | 내용 |
|---|---|
| 2분 | 규칙 설명 (모둠마다 재료 1가지, 물품 조합식, 미션 카드) |
| 2분 | 자급자족 시간 – 무역 금지, 혼자서는 아무것도 못 만든다는 것을 체험 |
| 12분 | 무역 시간 – 학생이 직접 쓴 제안문으로 거래, 물품 제작 |
| 4분 | 결과 화면의 "무역 전후 비교"를 보며 토론 |

교사 화면에서 시간·재료 지급량을 바꿀 수 있습니다.

## 사용 방법
- 교사: 접속 → `교사` 탭 → 비밀번호 입력 → 입장 코드표를 모둠에 알려 주고 `게임 시작` → `무역 열기` → `게임 끝내기`
- 모둠: 접속 → 모둠 번호 + 4자리 입장 코드 입력
- `초기화`를 누르면 기록이 지워지고 입장 코드가 새로 만들어집니다.

## 규칙 요약
- 특산품: 1모둠 목재 / 2모둠 철광석 / 3모둠 면화 / 4모둠 식량 / 5모둠 석유 / 6모둠 금
- 점수: 기본 가공품은 재료 2종=30점, 3종=40점, 4종=50점 / 심화 가공품=100점 / 최종 완성품=200점. 심화 가공품은 기본 가공품 1개 이상, 최종 완성품은 심화 가공품 1개 이상을 재료로 사용합니다. 미션 달성 보너스는 별도입니다.
- 제안문은 10글자 이상, 수락 답장은 5글자 이상 직접 써야 합니다.
- 타이머는 안내용입니다. 시간이 0이 되어도 교사가 끝낼 때까지 계속 진행됩니다.
